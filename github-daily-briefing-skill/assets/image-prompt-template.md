# 图片生成提示词模板

将方括号内容替换为本次已核实信息。不要把未核实数据填入模板。

```text
制作一张 3:4 竖版中文科技编辑封面，建议画布 1080 × 1440 像素，主题为“GitHub AI 每日简报”。

设计方向：简洁、专业、现代的开源科技杂志风格；[填写品牌色或配色]；清晰网格、充足留白、对比明确。避免复杂霓虹、无意义代码墙、虚构界面、杂乱拼贴和多余装饰。

请严格按以下文字排版，逐字保留，不要改写、翻译、增删或编造任何内容：

顶部小字：[日期] · GitHub AI 每日简报
主标题：[主标题]
副标题：[一句趋势概括；没有可靠共同趋势时改成中性描述]

项目卡片（按顺序排版）：
1. [官方项目名]
   [一句已核实的核心功能]
2. [官方项目名]
   [一句已核实的核心功能]
3. [官方项目名]
   [一句已核实的核心功能]
4. [官方项目名]
   [一句已核实的核心功能]
5. [官方项目名]
   [一句已核实的核心功能]

底部：[简短总结或署名]
数据说明（仅在使用数据时填写）：[统计口径与时间]

排版要求：主标题最醒目；项目名清楚，描述简洁易读；卡片对齐、间距一致；所有文字位于安全边距内。保持仓库名、数字、日期和中文原样。不要新增 Logo、网址、数据、项目或装饰文字。
```

## 生成与叠字建议

多数图像模型对中文和仓库名的逐字呈现不稳定。若文字必须准确，先用相同视觉描述生成不含文字的背景与装饰，然后在图像编辑器或排版工具中叠加上面的最终文案。完成后逐项比对事实核对表，重点检查汉字、仓库名、数字、日期、项目数量和来源说明。
