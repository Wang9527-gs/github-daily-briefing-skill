# 3:4 竖版封面设计规则

## 画布与气质

- 画幅：3:4 竖版；常用导出尺寸可设为 1080 × 1440 px。
- 气质：简洁、专业、现代的开源科技编辑设计。优先清晰网格、留白和稳定对齐。
- 颜色：以深蓝、炭黑或浅色纸面为主底色，搭配一至两个科技强调色；主要文字颜色控制在三种以内。根据发布平台和用户品牌素材调整，不默认套用固定品牌。
- 光效和装饰从简。避免密集霓虹、复杂电路纹理、无意义代码墙、虚构界面和明显拼贴感。

## 信息层级

1. 顶部：日期与系列标识（如“GitHub AI 每日简报”）。
2. 主标题：清楚表达当天主题；数字或关键词可突出，但不能遮挡标题。
3. 副标题：一句话说清当天最可信的共同趋势；如果看不出共同主题，就写中性说明，不强行总结趋势。
4. 主体：最多 5 张项目卡片，按重要性排列。每张卡片包含官方项目名和一句核心功能；可用小图标或简洁符号区分，但不要用会误导项目能力的图示。
5. 底部：一条短总结、来源说明或品牌署名。确有指标时，附近标注口径或统计时点。

## 字体与可读性

- 中文用清晰、现代的无衬线字体，保证标题与正文对比充分。
- 项目名称可保留拉丁字母和标点，不得替换、漏字或改大小写。
- 保持足够边距和卡片间距，视觉阅读顺序明确。
- 手机屏幕缩略查看时，标题与项目名仍能识别；正文不应过小。
- 所有具体文案以已核实的最终文本为准。不要让图像模型自行改写、补充数据或添加额外文字。

## 质量检查

生成或排版后检查：画幅是否为 3:4；项目卡片是否与文案数量一致；中文是否有错字、乱码或重复；仓库名、数字、单位和日期是否与核对表一致；文字是否被裁切、遮挡或低对比；画面是否出现提示词之外的徽标或数据。发现文字错误时，优先改用可控排版叠字，而非接受错字。
