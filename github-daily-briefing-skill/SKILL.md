# Github 每日简报 Skill

把当天的 GitHub AI 热门项目日报，转成一张准确、易读、克制的 3:4 竖版科技封面。中文展示名称为“Github 每日简报 Skill”。默认只交付策划文案与提示词；用户明确要求生成图片且当前环境支持时，再调用图像工具。

## 何时使用

- 用户提供一份中文 GitHub AI 热门项目日报，通常包含约 5 个项目，希望压缩成封面内容。
- 用户希望制作每日开源 AI 项目简报、趋势图或竖版科技封面。

## 输入

优先使用用户提供的日报、项目列表、日期、数据来源和品牌素材。用户只给主题、没有日报时，先说明需要当天候选项目或获准进行实时检索；不要编造“今日热门榜单”。

## 工作流程

1. 阅读 `references/copywriting-rules.md`，逐项拆分项目名称、功能描述、指标、日期和来源。
2. 核对项目与关键事实。优先检查项目官方 GitHub 仓库、官方文档或发布说明；平台热度数据应核对其定义、统计时间和榜单口径。记录来源链接与核对时间。不要把累计 Star 数说成单日新增。
3. 有来源冲突或无法访问时，标出“待核实”，缩小或删除对应主张；不以推测补齐。若项目候选数量或榜单口径不明，说明选择范围，不声称代表全站排名。
4. 选出最多 5 个最值得展示的项目。按重要性排序，每个项目只保留一个经核实的核心功能，用普通读者能理解的短句表达。
5. 按 `references/design-rules.md` 组织 3:4 竖版信息层级。先控制文字长度，再决定视觉元素，避免拥挤。
6. 阅读 `assets/image-prompt-template.md`，填入已核实内容，输出一份可直接交给图像模型的中文提示词。明确要求模型准确呈现中文；若工具常产生文字错误，可建议先生成无字底图，再用排版工具叠加文字。
7. 按下方交付格式给出结果。用户要求生成图片时，再按可用工具流程生成，并检查图片中的中文、项目名、数量、数字和版式；发现错误则修正或说明限制。

## 交付格式

### 事实核对
| 项目 | 核实后的事实 | 来源 | 状态 |

### 封面文案
- 日期与主标题
- 一句趋势副标题
- 最多 5 条项目卡片：项目名 + 一句核心价值
- 一句底部总结

### 生图提示词
给出完整、可复制的提示词，并写明比例 3:4、文字内容和排版要求。

若某条信息无法核实，在核对表中解释原因。不要把未核实项悄悄放进封面。
